# Jabra Video Konferans Türkiye - Toplantı Odası Video ve Ses Çözümleri

Toplantı odaları, huddle room'lar ve yönetim kurulu salonları için Jabra PanaCast video sistemleri ve Speak2 / Speak serisi konferans hoparlörlerini bir araya getiren özel portal.

## 🚀 Özellikler

- **İnteraktif Oda Konfigüratörü:** Kişi sayısı, oda boyutu ve platform tercihlerine (Microsoft Teams Rooms, Zoom Rooms, BYOD) göre anında en uygun video bar ve hoparlör kombinasyonunu öneren sihirbaz.
- **Speak2 360° LED Mikrofon Vitrini:** Ses kalitesi ve gürültü seviyesini gösteren interaktif ses simülasyonu.
- **Karşılaştırma Aracı:** PanaCast ve Speak sistemlerini teknik özellikleriyle yan yana kıyaslama.
- **Resmi Jabra GN Logosu:** Orijinal Jabra kurumsal kimliği ve aydınlık tema.

## 🛠️ Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın (Port 3002)
npm run dev

# Üretim derlemesi oluşturun
npm run build
npm run start
```
